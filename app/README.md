# app

The claude-livekit desktop app: Tauri v2, a React frontend in `src/` and a Rust core in `src-tauri/`. Run it with `just app dev` from the repo root; `just app` lists every command.

See [docs/tauri-notes.md](../docs/tauri-notes.md) for how the pieces fit and [docs/roadmap.md](../docs/roadmap.md) for what it does so far.
